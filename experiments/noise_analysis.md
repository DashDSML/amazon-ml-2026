# Noise analysis of training pairs (NonStandard T18)

Train data only. Seed 42. 50,000 matched (S1, S2/S3) pairs per country (half S2, half S3), 2,500 distractors per country, 50,000 S1 records for surface stats. Generated by `notebooks/noise_analysis.py`.

Token classes (S1 token → other-record token): exact; accent (equal after accent folding); number_format (equal after stripping leading zeros); number_edit (one digit edited); typo (OSA distance ≤1/≤2/≤3 for tokens of ≤4/≤7/8+ chars and fuzz ratio ≥60; an adjacent swap is 1 edit); abbreviation (other side is an in-order subsequence with the same first letter, ≥2 chars shorter and ≤75% of the length, e.g. road→rd); expansion (the reverse); merge (two S1 tokens glued together); substitution (the single leftover token on each side); heavy_typo (leftover pair with the same first letter and fuzz ratio ≥50, e.g. equipment→euspmeent); dropped (in S1 only); added (in the other record only). Tokens are `\w+` after NFKC + casefold. Names in non-Latin script are excluded from token stats.

Hand-written findings from these tables live in `experiments/noise_findings.md`
(not here, so re-running this script never clobbers them).
